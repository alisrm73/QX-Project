  - اشتراك ChatGPT لا يعني أن OpenAI API مجانية؛ لم يثبت وجود Worker منشور أو أسرار معدّة أو أن نقطة الاتصال الافتراضية مملوكة للمستخدم.

- **الحالة:** تقييم وقرار مثبتان؛ لم يتم نشر Worker أو الاتصال بخدمة مدفوعة.
- **الاعتماديات:** شرط المجانية وموافقة المستخدم لأي خدمة خارجية.
- **الخطوة التالية:** استبعاد الأجزاء المدفوعة من خطة التكامل، ومراجعة أي بديل محلي قبل اعتماده.
